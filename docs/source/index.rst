S2Generator's documentation
===========================

**Version**: |version|

Welcome to **S2Generator**, a Python library for **series–symbol**
synthetic data. Time series are treated as the external response of a
complex dynamical system: a symbolic expression :math:`f(\cdot)` is
excited by a stimulus series :math:`X`, and the response
:math:`Y = f(X)` is recorded.
